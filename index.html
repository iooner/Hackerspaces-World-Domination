🌍 Hackerspaces World Domination

A live map of hackerspaces around the world.

This globe aggregates data from two sources: SpaceAPI — a real-time open API standard that hackerspaces use to publish their status — and mapall.space, which compiles static data from wiki.hackerspaces.org. SpaceAPI spaces update every few hours; wiki spaces are static and shown in blue.

Status colors

  • 🟢 Green — currently open (SpaceAPI live)
  • 🟡 Yellow — open to members only, via the open_to_visitors field (proposed for SpaceAPI schema v16 ↗)
  • 🔴 Red — currently closed (SpaceAPI live)
  • ⚪ White — status unknown; API temporarily unavailable, space kept visible for 30 days
  • 🔵 Blue — static data from wiki.hackerspaces.org / mapall.space, no live status
  • 🟠 Orange (footer) — spaces whose API has been unreachable for over 30 days and have been removed from the map

My space isn't on the map 🗺️

Two ways to get listed:

  • SpaceAPI — implement the SpaceAPI standard and submit your endpoint to the directory. You'll get a live colored dot and real-time status.
  • Wiki — register on wiki.hackerspaces.org following their guidelines. You'll appear as a blue static dot.

We don't maintain a manual list — if you're in SpaceAPI or the wiki, you're in automatically.

My space is wrong / misplaced 📍

Coordinates and info come directly from the sources above — we don't store them independently. Fix them at the source: update your SpaceAPI endpoint, or edit your wiki page. Changes will appear on the next cache update (every few hours).

Why no FabLabs? 🤔

This is Hackerspaces World Domination, not FabLabs World Collaboration. We're dead serious about our chaos here. 😏
